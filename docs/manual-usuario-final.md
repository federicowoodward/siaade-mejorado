# 1. Introducción

Este sistema es una plataforma web diseñada para modernizar y simplificar la gestión académica de la institución. Permite administrar alumnos, docentes, materias, inscripciones, exámenes y datos personales de forma integrada, con una interfaz más clara y accesible que la versión anterior.

El objetivo principal es brindar a cada rol **alumno, docente, preceptor, secretario y director** una experiencia de uso intuitiva que reduzca tiempos de búsqueda, disminuya errores y mejore la disponibilidad de la información académica.

Este manual fue elaborado para guiar al usuario final en el uso cotidiano del sistema. Incluye los pasos necesarios para acceder, navegar por las distintas secciones y realizar las tareas más frecuentes. Su propósito es ofrecer una referencia rápida y confiable, especialmente útil para quienes utilizan la plataforma por primera vez o necesitan repasar algún procedimiento puntual.

## **1.1 Propósito del sistema**

### **Descripción**

El sistema tiene como propósito modernizar y centralizar la gestión académica de la institución, permitiendo que alumnos, docentes, preceptor, secretario y director accedan a información actualizada y realicen sus tareas diarias de forma más simple y eficiente.

Resuelve necesidades clave como:

- Consulta rápida de información académica.
- Inscripciones a materias y exámenes.
- Gestión de notas, asistencia y mesas de examen.
- Administración de usuarios y datos personales.

En el contexto institucional, aporta mayor orden, trazabilidad y coherencia en los procesos, reduciendo la carga operativa y mejorando la experiencia de quienes interactúan con el sistema.

## **1.2 Alcance**

### **Definición del alcance**

El sistema cubre los procesos principales de la gestión académica:

- Administración de usuarios y roles.
- Gestión de materias y asignación de docentes/preceptores.
- Inscripciones a materias y exámenes.
- Administración de exámenes parciales y finales.
- Visualización de notas, estados académicos y asistencias.
- Gestión de datos personales.

### **Incluido en este manual**

Este manual documenta:

- Acceso y autenticación.
- Navegación general del sistema.
- Funcionalidades disponibles por rol (alumno, docente, preceptor, secretario, director).
- Procedimientos para tareas frecuentes (inscribirse, ver notas, gestionar usuarios, etc.).
- Vistas principales y su propósito.

### **Paso a paso detallado**

Este documento detalla únicamente las pantallas del sistema accesibles desde el menú principal y las acciones previstas para el usuario final. No se documentan prototipos, flujos técnicos ocultos ni configuraciones internas.

## **1.3 Público objetivo**

### **Usuarios destinatarios**

Este manual está dirigido a:

- **Alumnos:** para consultar su situación académica, inscribirse y revisar información personal.
- **Docentes:** para visualizar materias asignadas, cargar notas y revisar listas de estudiantes.
- **Preceptor:** para gestionar cursos y estados académicos.
- **Secretario:** para administrar mesas de examen, usuarios y procesos generales.
- **Director:** para la gestión integral de usuarios y parámetros del sistema.

### **Nivel de conocimiento esperado**

El lector no necesita conocimientos técnicos avanzados. Se espera únicamente:

- Manejo básico de navegadores web.
- Capacidad de seguir instrucciones paso a paso.
- Familiaridad general con tareas administrativas académicas.

La guía está redactada para que cualquier usuario pueda comprenderla sin conocimientos previos del sistema.

## **1.4 Breve descripción general**

### **Resumen general del sistema**

El sistema es una plataforma web que integra toda la gestión académica institucional. Centraliza información, permite realizar trámites desde cualquier dispositivo y ofrece una interfaz moderna y fácil de usar.

### **Principales módulos**

- **Usuarios:** altas, bajas y modificación de datos.
- **Materias:** detalle, docentes asignados, estudiantes inscriptos.
- **Parciales y notas:** creación, edición y carga.
- **Mesas de examen finales:** creación, inscripción y registro de resultados.
- **Situación académica:** resumen de materias cursadas, pendientes y aprobadas.
- **Datos personales:** consulta y actualización.

### **Relación entre procesos**

- Los usuarios acceden al sistema según su rol, lo que define las acciones disponibles.
- Los alumnos interactúan con materias y exámenes; los docentes registran notas; los preceptores y secretarios supervisan y administran los procesos; y los administradores aseguran la coherencia general de datos.
- Toda la información fluye hacia un conjunto centralizado que permite consultar, gestionar y auditar la actividad académica en tiempo real.

### **Perfiles de usuario disponibles**

El sistema define distintos perfiles de usuario, cada uno con permisos específicos:

- **Alumno:**
    - Consulta su situación académica.
    - Visualiza materias, inscripciones, mesas de examen y notas.
    - Actualiza parte de sus datos personales (según permisos definidos).
- **Docente:**
    - Visualiza las materias a su cargo.
    - Consulta listados de alumnos.
    - Carga y actualiza notas de exámenes parciales.
- **Preceptor:**
    - Consulta cursos y comisiones.
    - Supervisa situación académica general de los alumnos.
- **Secretario:**
    - Administra mesas de examen.
    - Gestiona inscripciones y resultados finales.
    - Colabora en la gestión general académica.
    - Habilita y deshabilita cuentas.
- Director:
    - Puede visualizar todos los datos del sistema.
    - Puede revisar datos de auditoria.

# 3. Instalación o acceso

## 3.1 Acceso mediante navegador

El sistema SIAD es una aplicación web que se utiliza directamente desde el navegador. No requiere instalar programas adicionales en la computadora del usuario.

### Pasos para acceder

1. Abrir un navegador web compatible (Chrome, Edge o Firefox).
2. Ingresar la **URL oficial del sistema**, provista por la institución (por ejemplo: `https://siad.<dominio-institucional>`).
3. Esperar a que cargue la **pantalla de inicio de sesión**, donde se visualiza:
    - el logo de la institución,
    - el formulario de acceso con campos de **usuario** y **contraseña**,
    - y opciones adicionales para **recuperar contraseña**.

> (Se recomienda incluir aquí una captura de pantalla de la **pantalla de inicio de sesión**, mostrando el logo y el formulario de acceso).

### Recomendaciones de seguridad al ingresar

- Verificar que la dirección comience con `https://` y que el navegador indique conexión segura.
- No compartir usuario ni contraseña con otras personas.
- Evitar guardar la contraseña en computadoras públicas o compartidas.
- Al finalizar, cerrar sesión utilizando la opción correspondiente del menú superior.

### Sin instalación local

- El acceso se realiza completamente en línea; **no es necesario instalar** software en la computadora del usuario.
- Las actualizaciones del sistema se aplican de forma centralizada por el equipo técnico.
- Los usuarios siempre acceden a la versión vigente del sistema simplemente ingresando a la URL desde el navegador.

## 3.2 Recuperación de contraseña

La pantalla de autenticación incluye un flujo de recuperación de contraseña para usuarios que no recuerdan sus datos de acceso.

### Flujo de recuperación desde la pantalla de inicio de sesión

1. Ingresar a la URL oficial del SIAD.
2. En la pantalla de acceso, seleccionar la opción **“Recuperar”** o **“Recuperar contraseña”**.
3. Completar el campo solicitado con el **correo electrónico** o **CUIL** registrado en la institución.
4. Confirmar la solicitud utilizando el botón de envío.
5. El sistema enviará un **código** o **enlace de recuperación** al correo registrado.
6. Desde el correo recibido:
    - ingresar al enlace o pantalla indicada;
    - escribir el código, si corresponde;
    - definir una **nueva contraseña**, respetando las políticas indicadas en pantalla (longitud mínima, combinación de mayúsculas, minúsculas y números).
7. Guardar la nueva contraseña y volver a la pestaña de **“Login”** para iniciar sesión con los datos actualizados.

> (Se recomienda incluir aquí una captura de pantalla de la **pestaña de recuperación** y otra del **formulario para definir la nueva contraseña**).

### Si el correo de recuperación no llega

- Revisar la carpeta de **correo no deseado / spam**.
- Verificar que el correo utilizado coincida con el informado a la institución.
- Esperar unos minutos y volver a intentar.
- Si la situación persiste, contactar a la **mesa de ayuda** o a **secretaría** para que verifiquen los datos y, si es necesario, restablezcan el acceso por otro medio.

### Cambio de contraseña desde el perfil

Además del flujo de recuperación, los usuarios pueden cambiar su contraseña cuando ya están autenticados:

1. Iniciar sesión en el sistema.
2. Acceder a la sección **“Datos personales”** desde:
    - el menú superior (**“Mi perfil / Datos personales”**), o
    - la opción correspondiente del menú lateral.
3. Utilizar el botón **“Cambiar contraseña”**.
4. Completar el formulario indicando:
    - contraseña actual (si se solicita),
    - nueva contraseña,
    - confirmación de la nueva contraseña.
5. Guardar los cambios y volver a iniciar sesión si el sistema lo requiere.

> (Se recomienda incluir una captura de pantalla del **módulo de Datos personales** destacando el botón de “Cambiar contraseña”).

# 4. Navegación general

## 4.1 Estructura general de la interfaz

Una vez iniciada la sesión, todas las pantallas del SIAD comparten una estructura común:

- **Barra superior fija:** muestra el logo de la institución y el usuario actualmente conectado.
- **Menú lateral:** ubicado en el lado izquierdo, con las opciones de navegación principales según el rol.
- **Área de contenido principal:** sector central donde se muestran tablas, formularios y detalles de cada módulo.
- **Barrra de navegación interna (breadcrumbs):** en la parte superior del contenido, indica la ruta actual y permite volver a pantallas anteriores.

> (Se recomienda incluir aquí una captura de pantalla de la **pantalla principal**, donde se vean la barra superior, el menú lateral y el área de contenido).

## 4.2 Barra superior (menú superior)

La barra superior aparece cuando el usuario está autenticado e incluye:

- El **logo** de la institución o del sistema SIAD.
- El **nombre completo** del usuario conectado.
- El **rol actual** (por ejemplo: Alumno, Docente, Preceptor, Secretario, Director).
- Un **menú desplegable de usuario**, desde el cual se puede:
    - acceder a **“Mi perfil / Datos personales”**;
    - cerrar sesión de forma segura.

En dispositivos móviles, la barra superior también incluye un **botón de menú** (ícono de tres líneas) que permite abrir o cerrar el menú lateral.

> (Se recomienda incluir una captura de pantalla del **menú de usuario desplegado**, mostrando las opciones “Mi perfil” y “Cerrar sesión”).

## 4.3 Menú lateral

El menú lateral agrupa los módulos principales del sistema. Su contenido se adapta automáticamente según el rol del usuario:

- **Alumno:**
    - Inicio
    - Inscripciones a exámenes
    - Situación académica
- **Docente:**
    - Inicio
    - Materias
    - Finales
- **Preceptor / Secretario / Director:**
    - Inicio
    - Materias
    - Usuarios
    - Finales
    - Avisos
    - Auditoría (según permisos definidos por la institución)

Cada opción se acompaña de un ícono sencillo que facilita la identificación del módulo (casa para inicio, libro para materias y finales, grupo de personas para usuarios, campana para avisos, gráfico para auditoría).

Para cambiar de módulo:

1. Hacer clic en la opción deseada del menú lateral.
2. Verificar que la opción seleccionada queda **resaltada**.
3. Revisar que el título del contenido principal coincida con el módulo elegido.

> (Se recomienda incluir aquí una captura de pantalla del **menú lateral completo**, con ejemplos de las opciones visibles para distintos roles).

## 4.4 Contenido principal y breadcrumbs

Dentro de cada módulo, el área principal suele incluir:

- Un **encabezado de página** con:
    - título del módulo (por ejemplo, “Gestión de usuarios”, “Mesas de examen”, “Situación académica”);
    - breve descripción de lo que se puede hacer en esa pantalla.
- Una **barra de acciones**, donde se ubican botones como:
    - **“Nuevo usuario”**;
    - **“Crear mesa”**;
    - **“Crear examen”**;
    - **“Actualizar”**;
    - **“Imprimir comprobante”**;
    - filtros y búsqueda.
- Una o varias **tablas de datos**, donde se listan alumnos, usuarios, materias, exámenes, avisos u otras entidades.

En la parte superior del contenido se presenta la barra de **migajas de pan** (breadcrumbs), que indica la ruta navegada. Algunos ejemplos:

- Inicio › Usuarios › Detalle de usuario
- Inicio › Finales › Mesas de examen
- Inicio › Alumno › Inscripción a examen

Al hacer clic en cada nivel de la barra, el usuario puede volver fácilmente a pantallas anteriores sin utilizar el botón “Atrás” del navegador.

> (Se recomienda incluir aquí una captura de pantalla donde se vean las **migajas de pan** y una **tabla de resultados**).

## 4.5 Navegación en dispositivos móviles

El sistema está preparado para funcionar en pantallas pequeñas (teléfonos, tablets):

- El **menú lateral** se oculta por defecto y se abre mediante el botón de menú de la barra superior.
- El contenido se organiza en una columna, con desplazamiento vertical.
- Las tablas permiten **desplazamiento horizontal** cuando la información excede el ancho de la pantalla.
- Algunos textos o columnas se simplifican para garantizar la lectura.
